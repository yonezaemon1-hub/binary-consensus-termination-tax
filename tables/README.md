# Finite computational tables

This repository supports two published preprints in the same line.

## Paper 3: clockless termination

- `clockless_bounds_selected.csv` — representative finite state/bit bounds for known `n` and known dynamic diameter `D`.
- `../COMPUTATIONAL_EVIDENCE_PAPER3.md` — interpretation and claim boundary.

## Paper 4: periodic state–phase tradeoff

- `state_phase_bounds_selected.csv` — representative finite lower/upper state bounds across `P`.
- `../audit/computational_evidence.py` — standard-library generator for the wider finite grid.

These are arithmetic audits/visualization data; the manuscript proofs remain the source of the universal results.
